Comment ça marche ?

  • Rendez-vous : chaque demande en ligne arrive « à confirmer ». Cliquez Confirmer : le client reçoit automatiquement un email de confirmation. Annuler lui envoie un email d’annulation. Le créneau est bloqué tant que le RDV est en attente ou confirmé.
  • Devis : le client reçoit un devis estimatif PDF automatiquement. Vous recevez le même PDF par email, avec ses photos éventuelles. Marquez-le Traité une fois recontacté. Le bouton PDF réouvre le devis.
  • Messages : vous recevez chaque message par email ; répondez-y directement depuis votre messagerie (le « Répondre à » pointe vers le client).
  • Fermetures : bloquez vos congés pour que personne ne réserve pendant votre absence.
  • Tarifs : modifiez le fichier config/pricing.json sur le serveur pour changer les prix, puis redémarrez le site. Les horaires sont dans config/garage.json.
